Сюда кладётся подключение Spark к каталогу таблиц и хранилищу — его пишет
студент (работа 4): файл `spark-defaults.conf`. Учётные данные пишутся
ссылками `${ENV:ИМЯ}` на переменные `.env`. Каталог монтируется только для
чтения в сервисы `spark` и `stream`; при каждом запуске точка входа образа
подставляет переменные и дописывает строки стенда (расширения Iceberg,
память драйвера, число разделов при перемешивании) — они побеждают.
