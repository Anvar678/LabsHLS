Сюда кладётся каталог Trino — его пишет студент (работа 4, вариант с движком
Trino). Файл `<каталог>.properties` — один каталог, имя файла — имя каталога.
Учётные данные пишутся ссылками `${ENV:ИМЯ}` на переменные `.env`. Каталог
монтируется только для чтения в сервис `engine` как `/etc/trino/catalog`;
Trino читает его при старте: после правки — `docker compose restart engine`.
