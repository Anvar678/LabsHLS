# Сборщик GH Archive для ЛР1

Точка входа — main.py. Реализована обязательная часть ЛР1 варианта 31.
Используется стандартная библиотека Python.

## Режимы

- record — постоянная запись новых часовых архивов.
  После догрузки накопившихся часов ожидает следующие архивы.
  Самостоятельно по истечении суток не завершается.
- backfill — загрузка заданного исторического периода.
  Завершается после обработки всех часов интервала.

Режим передаётся первым аргументом. Если аргумент отсутствует,
используется COLLECTOR_MODE, по умолчанию record.

Режимы produce и replay в версии ЛР1 не реализованы.

## Настройки

Настройки читаются из окружения контейнера. Python-программа сама .env не читает.

| Переменная | Значение по умолчанию | Назначение |
|---|---|---|
| SOURCE | Нет, обязательна | Для этой реализации — github |
| SOURCE_FILTER | Нет, обязательна | Типы событий через запятую |
| COLLECTOR_MODE | record | Режим при отсутствии первого аргумента |
| COLLECTOR_RAW_DIR | /data/raw | Корень сырых данных |
| COLLECTOR_OUT_DIR | stream или history внутри COLLECTOR_RAW_DIR | Вывод выбранного режима |
| COLLECTOR_RAW_LIMIT_GB | 20 | Предел суммы закрытых файлов stream + history |
| COLLECTOR_BASE_URL | Нет, обязательна | Базовый адрес часовых архивов |
| COLLECTOR_USER_AGENT | Нет, обязательна | Название программы и контактный email |
| COLLECTOR_POLL_SECONDS | 60 | Пауза ожидания следующего завершённого часа |
| COLLECTOR_HTTP_TIMEOUT | 60 | Таймаут сетевой операции, секунды |
| COLLECTOR_MIN_SIZE_RATIO | 0.2 | Минимальный размер относительно предыдущего часа; 0 отключает сравнение |
| COLLECTOR_HISTORY_FROM | Нет, обязательна для backfill | Начало истории включительно |
| COLLECTOR_HISTORY_TO | Нет, обязательна для backfill | Конец истории, не включается |

COLLECTOR_OUT_DIR должен соответствовать стандартному каталогу выбранного режима:
stream для record, history для backfill.

Даты истории задаются в ISO 8601. Рекомендуется явно указывать UTC окончанием Z.
Если пояс отсутствует, программа трактует дату как UTC.
Границы должны совпадать с началом часа; FROM < TO; TO не должен быть в будущем.

Рабочие значения варианта:

```ini
SOURCE=github
SOURCE_FILTER=PullRequestEvent,IssuesEvent,IssueCommentEvent
COLLECTOR_MODE=record
COLLECTOR_RAW_LIMIT_GB=20
COLLECTOR_BASE_URL=https://storage.googleapis.com/data.gharchive.org
```

COLLECTOR_USER_AGENT содержит gharchive-lab31/1.0 и контактный email в скобках.
Контакт задаётся локально в .env.

## Запуск

Все команды выполняются из ~/stand.

Загруженный в ЛР1 исторический период:

```bash
docker compose run --rm \
  -e COLLECTOR_HISTORY_FROM=2026-10-05T12:00:00Z \
  -e COLLECTOR_HISTORY_TO=2026-10-12T12:00:00Z \
  collector backfill
```

Базовый адрес и остальные настройки передаются из .env.

Запуск службы:

```bash
docker compose --profile lab1 up -d
```

Просмотр состояния и журнала:

```bash
docker compose ps -a collector
docker compose logs -f --tail=20 collector
```

Ctrl+C при просмотре logs завершает только просмотр журнала.

Перезапуск службы:

```bash
docker compose restart -t 90 collector
```

Остановка и повторный запуск:

```bash
docker compose stop -t 90 collector
docker compose start collector
```

Повторный backfill с тем же периодом пропускает уже обработанные часы.
Незавершённый час обрабатывается повторно.

Изменения main.py применяются после перезапуска процесса.
При добавлении зависимостей их нужно записать в collector/requirements.txt
и пересобрать образ.

## Файлы и состояние

- data/raw/stream/dt=ГГГГ-ММ-ДД/hour=ЧЧ/ — поток по часу получения UTC.
- data/raw/history/dt=ГГГГ-ММ-ДД/ — история по дате события UTC.
- data/raw/state/collector.sqlite3 — позиция и индекс ключей.
- data/raw/state/collector.lock — блокировка обработки между экземплярами.
- data/raw/state/work/ — временная загрузка и временные выходные файлы.

Сохранённый формат — UTF-8 JSONL, сжатый gzip.
Файлы публикуются только после закрытия.
Порог смены выходного файла — 64 МиБ распакованного JSONL либо смена партиции.

Каждая сохранённая запись содержит исходные поля и:
event_key, event_time, received_at, source.

После сбоя индекс готовых файлов восстанавливается; временные файлы
пересоздаются при повторной обработке часа.
Повторы исключаются отдельно внутри stream и внутри history.

Изменение источника или фильтра относительно сохранённого состояния
отклоняется программой. Служебное состояние нельзя удалять для обычного
продолжения сбора.

## Ошибки и предел хранения

- 404 нового архива вызывает ожидание и повтор того же часа.
- Сетевые ошибки, 429 и 5xx вызывают повтор с растущей паузой.
- Пауза экспоненциального повтора ограничена 600 секундами;
  Retry-After может увеличить её. Добавляется небольшая случайная задержка.
- Content-Length проверяется, если передан сервером.
- gzip читается до конца, что проверяет его целостность.
- Подозрительно маленький архив запрашивается повторно.
  Сравнение размера не гарантирует полноту исходных событий.
- При достижении предела удаляются самые старые закрытые файлы.
  В предел входят stream и history; state в него не входит.

## Журнал

Одна строка JSON на событие программы. Основные сообщения:

- start — режим и начальная позиция;
- download_started — начало загрузки часа;
- download_finished — архив загружен и прошёл проверку размера;
- poll — события и байты до/после фильтра, повторы и сохранённые записи;
- closed — выходные файлы закрыты и результат часа зафиксирован;
- retry — ошибка, попытка и пауза;
- rotated — удаление старого файла;
- recovered — восстановление индекса готового файла;
- stop — завершение цикла;
- fatal — ошибка, завершившая процесс.

completed=true относится к успешно завершённому backfill.
completed=false при остановке record нормально: конечного периода у него нет.

Показатели events_per_minute относятся к числу событий в исходном
часовом архиве, делённому на 60, а не к скорости выполнения Python-программы.

## Проверка

Проверка повторяющихся ключей за дату:

```bash
set -o pipefail
zcat data/raw/stream/dt=2026-10-14/hour=*/*.jsonl.gz \
  | jq -r .event_key | sort | uniq -d | wc -l
```

Успешный результат — 0 без ошибок чтения и разбора JSON.
